# Oloi OS System Overview

## Purpose
Oloi OS is the operating system for Oloi Shorua.

## Architectural Layers

1. Oloi Shorua Framework
   - Independent philosophical framework.
   - Governs principles.
   - Lives outside application code.

2. Oloi OS Constitution
   - Converts framework principles into business rules.

3. Oloi OS
   - Software implementation.
   - Database, APIs, AI, CRM, Journey Engine and user interfaces.

## Rule
The software must remain aligned with the Framework but must not duplicate philosophical content inside the application.

Future work will be organised into:
- Traveller Domain
- Journey Domain
- Knowledge Domain
- Supplier Domain
- Operations Domain
- AI Domain
